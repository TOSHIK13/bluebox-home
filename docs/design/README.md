# Макеты Home

Утверждённый вариант — A (кадры A1–A4): `home-canvas/Main.dc.html` (A1), `Nav2` (строка каналов), `Nav3` (раскрытый столбик), `Nav4` (новая серия). B, C, D — отложенные варианты.
Артборд 960x540, 1 пикс макета = 1 dp (на ТВ 1080p 1 dp = 2 px). Файлы `.dc.html` открываются в Design-канвасе Claude (скрипт `support.js` подставляет он); исходник канваса: https://claude.ai/artifact/Py1ecNzFXLbG1c6ZRdfYse

Решения: строка «Продолжить просмотр» без названий на карточках; плашка «С2 · Е5»/«Фильм» и полоска прогресса на миниатюре; для новой серии только плашка «НОВАЯ» на карточке, без верхней надписи; подсказки внизу нет.
